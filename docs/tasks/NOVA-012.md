# NOVA-012 — ui-trading: EquityCurve (Recharts), responsive

**Status:** planned · **Owner:** — · **Branch:** task/NOVA-012 · **Depends on:** NOVA-011

## Goal
`@nova/ui-trading` exports `EquityCurve`: a responsive line chart of a backtest's equity (and optional NIFTY 50 benchmark) from `EquityPoint[]`, themed only by tokens, readable at 360px.

## Read first
- `AGENTS.md` (§5–8), `docs/DECISIONS.md` (D15, D17), `docs/COMPONENTS.md`
- `frontend/packages/contracts/src/backtest.ts` (`EquityPoint` only)
- `frontend/packages/ui-trading/{package.json,src/index.ts,src/format/money.ts}`
- `frontend/packages/ui-core/src/theme/tokens.css` (variable names: `--action`, `--chart-benchmark`, `--border-default`, `--text-muted`, `--font-mono`)
- `frontend/packages/ui-trading/src/components/ChargesBreakdown/*` (pattern: component, story, test, storyData)

## Files
Create in `frontend/packages/ui-trading/src/components/EquityCurve/`:
- `EquityCurve.tsx`, `EquityCurveTooltip.tsx`, `EquityCurve.stories.tsx`, `EquityCurve.test.tsx`, `storyData.ts`
Modify: `frontend/packages/ui-trading/{package.json,src/index.ts}`, `frontend/pnpm-lock.yaml` (via `pnpm install`), `docs/COMPONENTS.md`

## Build
1. Dep: `recharts` 3.x (exact latest stable) in ui-trading `dependencies`.
2. Props: `points: EquityPoint[]` (type import from `@nova/contracts`), `initialCapitalPaise?: number` (dashed reference line), `height?: number` (default 280; 220 below `md` via a `h-[220px] md:h-[280px]` wrapper when `height` is not given), `loading?`, `emptyText?` (default "No equity data"), `ariaLabel: string`, `className`.
3. Chart: `ResponsiveContainer` → `LineChart`. Equity line `stroke="var(--action)"`, width 2, no dots. Benchmark line only when any `benchmarkPaise` is non-null: `stroke="var(--chart-benchmark)"`, `strokeDasharray="4 4"`, name "NIFTY 50". Grid horizontal only, `stroke="var(--border-default)"`. Axes: tick `fill: var(--text-muted)`, font `var(--font-mono)`, size 11. X ticks as `MMM yy` (date-fns `format` on the `YYYY-MM-DD` string parsed with `parseISO`), `minTickGap` 32. Y ticks compact INR: add `formatInrCompact(paise)` to `format/money.ts` (`₹5.2L`, `₹1.23Cr`, `₹85K`, negatives with `−`) + tests.
4. `EquityCurveTooltip`: `bg-bg-raised border border-border-default rounded-md p-3`, date as `21 Sep 2026`, equity and benchmark via `formatInr(…, { decimals: 0 })` in mono, benchmark row only if present.
5. Legend: small custom row above the chart (not Recharts `Legend`): swatch + "Strategy", swatch + "NIFTY 50" when shown. `text-body-sm text-text-muted`.
6. Accessibility: wrapper `role="img"` with `aria-label={ariaLabel}`; a visually hidden `<p>` summary: "From {first date} to {last date}, equity {formatInr first} → {formatInr last}".
7. States: `loading` → ui-core `Skeleton` of the chart height; empty `points` → centred `emptyText` in `text-text-muted` at the same height.
8. `storyData.ts`: ~120 weekday points, hand-typed or generated by a plain loop with fixed numbers (no `Math.random`), valid per `EquityPointSchema` (test checks). Stories `Trading/EquityCurve`: Default (with benchmark), WithoutBenchmark, Loading, Empty, Narrow (360px viewport parameter).
9. Tests (stub `ResizeObserver`; give the container a size by mocking `ResponsiveContainer` to render children at 600×280 if needed): summary text, legend shows/hides "NIFTY 50", empty and loading states, `formatInrCompact` examples.
